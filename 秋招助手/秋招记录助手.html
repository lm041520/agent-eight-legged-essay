    创建专用 API Key

    登录智谱或阿里云百炼，单独创建一个用于本工具的 Key。

  2. 2
    选择兼容接口

    在下方「接口类型」中选择 OpenAI 兼容接口。

  3. 3
    填入模型与完整地址

    模型名照抄卡片代码；接口地址需包含 /chat/completions。

  4. 4
    测试后再识别截图

    先点击「测试连接」，通过后粘贴一张通知截图核对结果。

建议使用低额度专用 Key，不要将密钥截图或分享给他人。
